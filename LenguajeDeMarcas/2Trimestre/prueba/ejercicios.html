Guía de Ejercicios CSS: Portafolio Web

A continuación encontrarás todos los pasos para practicar CSS creando un portafolio web. Lee cada ejercicio y aplícalo a tu proyecto. Usa tu propio index.html (o el que se te haya dado) y un archivo styles.css para implementar estos pasos.

1. Estructura HTML Base

Copia y pega en tu propio archivo index.html la siguiente estructura (o revisa la que ya te fue proporcionada). Se compone de header, secciones para Sobre Mí, Proyectos, Habilidades, Contacto y un footer. Asegúrate de enlazar tu styles.css en el head. 

<!DOCTYPE html>
<html lang="es">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>Portafolio de Nombre Apellido</title>
  <!-- Vinculamos el archivo CSS externo -->
  <link rel="stylesheet" href="styles.css" />
</head>
<body>

  <header id="main-header">
    <h1 class="nombre">Nombre Apellido</h1>
    <nav class="menu">
      <ul>
        <li><a href="#about">Sobre Mí</a></li>
        <li><a href="#projects">Proyectos</a></li>
        <li><a href="#skills">Habilidades</a></li>
        <li><a href="#contact">Contacto</a></li>
      </ul>
    </nav>
  </header>

  <main>
    <section id="about">
      <!-- Contenido Sobre Mí -->
    </section>

    <section id="projects">
      <!-- Tarjetas de Proyectos -->
    </section>

    <section id="skills">
      <!-- Listado de habilidades -->
    </section>

    <section id="contact">
      <!-- Formulario o datos de contacto -->
    </section>
  </main>

  <footer>
    <!-- Texto de copyright -->
    &copy; 2025 Tu Nombre - Portafolio
  </footer>

</body>
</html>

A partir de aquí, te centrarás en crear o vaciar tu styles.css para resolver los siguientes ejercicios.

2. Selectores Básicos y Reset

  1. Reset y box-sizing: Añade en styles.css un pequeño reset que quite márgenes y paddings por defecto, y pon box-sizing: border-box; para todos los elementos con el selector universal *.
  2. Estilo global para body: Asigna una fuente base, un color de fondo suave (por ejemplo, #f0f0f0) y un color de texto oscuro (#333). Deja el line-height en 1.6 y reintroduce márgenes o padding básicos si lo deseas.
  3. Encabezado (#main-header): Para probar un selector ID, aplica un fondo llamativo (podría ser #4CAF50 o el color que elijas) y un color de texto blanco, verificando que el cabecero destaque.
  4. Texto en h1, h2, p: Añade márgenes inferiores para separar títulos y párrafos. Aplica el tamaño de fuente que creas adecuado para jerarquizar.

Con esto, tu página debería tener un estilo general, sin márgenes pegados y con tipografía consistente.

3. Colores, Fuentes y Textos

  1. Paleta de colores: Elige un color primario, uno secundario, y colores neutros (fondo claro, texto oscuro). Úsalos para el header, footer, títulos y botones.
  2. Fuente personalizada (opcional): Usa Google Fonts o @import en tu CSS para una fuente como Open Sans, Roboto, etc. Reemplaza la fuente por defecto del body con la nueva fuente.
  3. Jerarquía tipográfica: Ajusta tamaños en h1, h2 y p para una lectura clara. Por ejemplo, h1 grande (2em), h2 un poco más pequeño (1.5em), y el párrafo (1em).
  4. Margen y padding: Añade padding en cada sección (section) para que el contenido no se pegue a los bordes. Ajusta margin-bottom en títulos si lo ves necesario.

Tras este paso, la tipografía y colores deberían lucir más profesionales y organizados.

4. Modelo de Caja (Box Model)

  1. Secciones: Alterna fondos entre secciones (blanco, gris claro, etc.) y asigna padding: 40px (por ejemplo) arriba y abajo.
  2. Tarjetas de Proyectos: Usa .project-card para aplicar padding, border (1px gris) y border-radius (5px). Añade margin entre tarjetas.
  3. Imágenes Responsivas: Dentro de .project-card, pon img { max-width: 100%; height: auto; } para que no excedan el ancho del contenedor.
  4. Lista de Habilidades: ul.skills-list sin viñetas (list-style: none;), y convierte cada li en un bloque con display: inline-block; o flex para que se muestren como “chips” con padding, fondo claro y border-radius.
  5. Formulario de Contacto: Aplica margin-bottom en los campos, un border suave, padding interno, y border-radius para inputs y textarea.

Con esto, verás cada bloque (tarjetas, habilidades, formulario) más definido y ordenado.

5. Posicionamiento (fixed, relative, absolute, sticky)

  1. Header Fijo: Haz que el header se quede arriba con position: fixed; top: 0; width: 100%;. Asegúrate de que el contenido principal no quede oculto (añade margin-top o padding-top en main).
  2. Flecha Scroll Down: Podrías posicionarla con position: absolute; dentro del header (el header debe tener position: relative;).
  3. Sticky (opcional): Prueba con position: sticky; en algún h2 o elemento para que se “pegue” al tope al hacer scroll en su contenedor.

El objetivo es practicar cómo fijar el menú de navegación, y colocar ciertos elementos de forma absoluta o sticky dentro de sus contenedores.

6. Distribución con Flexbox

  1. Header con Flexbox: Aplica display: flex;, justify-content: space-between; y align-items: center; para alinear el nombre a la izquierda y la navegación (ul) a la derecha (o en otra disposición que te guste).
  2. Menú en línea: Dentro del .menu ul, usa display: flex; y un gap para separar cada li. Quita list-style si lo deseas.
  3. Tarjetas de Proyectos (alternativa): En lugar de Grid, podrías usar display: flex; y flex-wrap: wrap; para que se reorganicen en varias filas al reducir la ventana.
  4. Lista de habilidades con flex: .skills-list { display: flex; flex-wrap: wrap; gap: 1em; } para repartir los li.

Observa cómo Flexbox facilita la distribución y el alineamiento en una dimensión (horizontal o vertical).

7. Diseño con Grid (opcional o complementario)

  1. Proyectos con Grid: Define display: grid; en la sección de proyectos, usa grid-template-columns para crear columnas, y gap para separar las tarjetas.
  2. Minmax/auto-fit: Experimenta con grid-template-columns: repeat(auto-fit, minmax(250px, 1fr)); para lograr un layout responsivo automático.
  3. Alineación: Utiliza justify-items y align-items para centrar el contenido dentro de cada “celda”.

CSS Grid te ayudará a gestionar la disposición de elementos en dos dimensiones (filas y columnas) de manera más declarativa.

8. Media Queries y Responsive

  1. Breakpoint para móvil: Crea una media query para (max-width: 600px) (u otro valor). Ajusta el header para que pase a columna, reduce el tamaño de fuente del h1, etc.
  2. Tarjetas en una sola columna: En pantallas pequeñas, podrías cambiar flex-direction a column o grid-template-columns: 1fr para que se apilen.
  3. Formulario adaptable: Asegúrate que input, textarea y el button tengan width: 100% en móviles si lo deseas.

Verifica el resultado en distintos anchos de pantalla. Responsive design te permite ofrecer una buena experiencia tanto en escritorio como en dispositivos móviles.

9. Pseudoclases y Pseudo-elementos

  1. Hover en enlaces: Cambia el color o subraya en a:hover.
  2. Estados del formulario: input:focus (cambia borde), input:invalid y input:valid para retroalimentación al usuario.
  3. Decoración con ::before / ::after: Por ejemplo, añade una línea bajo cada h2 con ::after o un ícono en la lista de habilidades con ::before.
  4. :nth-child( ) (opcional): Aplica estilos alternos a elementos pares o impares.

Con las pseudoclases y pseudo-elementos, tu portafolio tendrá detalles de interacción y decoración sin modificar el HTML.

10. Transiciones y Transformaciones

  1. Transición en Hover: Define transition en el estado base (por ejemplo, .project-card) para que los cambios de transform o box-shadow al hover sean suaves.
  2. Transformación de tarjetas: Aplica .project-card:hover { transform: translateY(-5px); ... } y una sombra suave para el efecto “levantar”.
  3. Botón hover: Cambia ligeramente el color de fondo en button:hover con una transición de 0.3s o similar.

Así consigues micro-interacciones sutiles que mejoran la experiencia de usuario.

11. Animaciones con @keyframes

  1. Flecha “bounce”: Crea @keyframes bounce y en .scroll-down usa animation: bounce 2s infinite; para que suba y baje.
  2. Fade-in en el header (opcional): Con @keyframes fadeIn y animation: fadeIn 1s para que aparezca progresivamente.
  3. Animación en habilidades (opcional): Por ejemplo, un “pulse” que cambie su color de fondo, o unas barras que se llenen (requiere más HTML).

Con @keyframes y animation puedes crear animaciones repetitivas o que ocurran solo al cargar la página.

12. Variables CSS (Custom Properties)

  1. Definir en :root: Crea variables como --color-primario, --color-secundario, --borde-redondeado, etc.
  2. Reemplaza valores: En tu CSS, donde usaste #4CAF50 o 5px repetidas veces, cambia a var(--color-primario) o var(--borde-redondeado).
  3. Prueba cambios: Cambia un solo valor en :root y verás cómo todos los elementos que usan esa variable se actualizan. Esto facilita la personalización del tema.

Variables CSS hacen tu código más mantenible y escalable.

Conclusión y Buenas Prácticas

  • Organiza tu CSS: Usa comentarios y secciones (header, secciones, footer, media queries) para que sea fácil de leer.
  • No abuses de los efectos: Aplica animaciones y transiciones con moderación para no sobrecargar la experiencia.
  • Prueba en varios dispositivos: Usa las herramientas del navegador para simular distintas resoluciones y confirma que todo se vea bien.
  • Valida tu HTML y CSS: Emplea validadores como W3C Validator para pulir errores y mejorar la accesibilidad.
  • Sigue aprendiendo: Una vez domines estos conceptos, puedes añadir JavaScript para menú desplegable, sliders, etc. También explorar Sass/SCSS para proyectos grandes.

¡Listo! Con esta guía has repasado desde selectores básicos hasta animaciones. Cualquier duda o problema, revisa la consola del navegador o pregunta a tu profesor/compañeros. ¡Sigue practicando y mejorando tu portafolio!
