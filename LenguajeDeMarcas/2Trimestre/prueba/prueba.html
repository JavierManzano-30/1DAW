Sobre Mí

Estoy en mi primer año de Desarrollo Web, aprendiendo cada día nuevas tecnologías y mejores prácticas. Proyectos

Blog Personal

Un blog personal estático construido con HTML5 y CSS3, con secciones de artículos, sobre mí y contacto. Sirve como bitácora para practicar maquetación web y aplicar estilos tipográficos y de diseño responsivo.

Juego del Memorama

Una pequeña aplicación de juego de memoria (matching game) implementada con HTML, CSS y JavaScript. Incluye tarjetas que se voltean al hacer clic, temporizador y conteo de intentos. Proyecto para practicar interactividad con JS y animaciones en CSS.

Tienda Online Demo

Prototipo de una página de tienda en línea. Presenta una galería de productos ficticios con sus imágenes, nombres y precios. Este proyecto se enfocó en el diseño responsive usando Flexbox y Grid para organizar los productos en diferentes tamaños de pantalla.
